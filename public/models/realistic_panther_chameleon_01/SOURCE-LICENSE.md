Posora uses the model only inside its interactive learning site. The source requires no attribution; Posora links the model page for transparency.

The model page identifies this specimen as an adult male panther chameleon (*Furcifer pardalis*), built with the 1DesignTool 3D template. It is used only to illustrate the broad reptile class, not as a Bangladeshi species. The source says the pose is static and procedural with PBR textures; the published “realistic” style is not photogrammetry.
