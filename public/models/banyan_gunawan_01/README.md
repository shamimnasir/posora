# Banyan tree photogrammetry scan

- Model: [BANYAN TREE by Jimmy Gunawan](https://sketchfab.com/3d-models/banyan-tree-704d83ff28c84dd487ef7dbfdbcdf2fb)
- License: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/); the source download panel confirms commercial use is allowed with attribution.
- Attribution: “BANYAN TREE” by Jimmy Gunawan, CC BY 4.0.
- Role: close-up scan of a banyan tree's lower trunk and aerial roots in Life → বাংলাদেশের গাছপালা → বট; it is not a whole-tree scan.
- The source describes this as a photogrammetry reconstruction from 12 photos. It does not specify a scientific species or location, so the site does not claim that this is a particular tree in Bangladesh.
- Source and derivative hashes, mesh statistics, and optimization steps: [asset-manifest.json](asset-manifest.json).
