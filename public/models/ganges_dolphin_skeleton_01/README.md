# Ganges river dolphin skeleton scan

- Subject: Ganges river dolphin (*Platanista gangetica*) skeleton, Natural History Museum of the University of Pisa specimen C 272.
- Source and creator record: [Wikimedia Commons file page](https://commons.wikimedia.org/wiki/File:Platanista_gangetica_3d_scan_Natural_History_Museum_University_of_Pisa_C_272.stl), uploader Patrizia17; [museum Sketchfab model](https://sketchfab.com/3d-models/ganges-river-dolphin-c5fbdf0ace47481eb25646a9c13debb5).
- License: [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). This is a commercial-use-compatible share-alike license; keep attribution and this license with the adapted model.
- Educational use: Bangladesh Life → বাংলাদেশের প্রাণী → শুশুক. The displayed object is a museum skeleton scan, not a living dolphin or a soft-tissue body model.
- Changes: converted binary STL to GLB, normalized its longest dimension, simplified the mesh for web delivery, and generated vertex normals. The adapted model remains CC BY-SA 4.0.
- Processing: `node scripts/convert-binary-stl-to-glb.mjs input.stl output.glb 120000`.
- Source/output hashes and geometry counts are recorded in [asset-manifest.json](asset-manifest.json).
