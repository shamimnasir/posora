# Nypa fruticans fruit-cluster model

- Source: [Nypa fruticans by zefruitlivingbeingidk](https://sketchfab.com/3d-models/nypa-fruticans-bb6dfbb59cb447cb83b29a48a3fe9b64)
- Creator credit: zefruitlivingbeingidk (Devin Truong)
- License: [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/)
- Scope: fruiting head / clustered fruits only. This is not a whole golpata plant and is not represented as a specimen scan.
- Optimization: reduced to 5% target vertex ratio, texture resized to 512 px and converted to WebP quality 80 for web delivery.
- Verification: rendered in Posora's local Three.js preview at 1440×900 and 390×844 on 2026-10-20. Both parses succeeded; visual evidence is recorded in `docs/animation-remake/evidence/licensed-models/`.

The model is used as a supplemental fruit-cluster specimen beside the teaching palm, not as a replacement for the whole plant.
