# Rice in bowl model

- Source: [Rice in bowl by Frid.blend](https://sketchfab.com/3d-models/rice-in-bowl-67c7c7d2fd0b4e0487ad4f689335d61a)
- Creator credit: Frid.blend
- License: [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/); commercial use allowed with attribution.
- Scope: a bowl of cooked rice used as the carbohydrate example. It is not a rice-and-dal meal and is not used as one.
- Source download: converted GLB, 1K texture, 1.5 MB; 32.2k triangles and 16.2k vertices per the source listing.
- Changes: scaled and positioned for Posora's Food tabletop; no source geometry was edited.
- Verification: desktop/mobile rendering and source credit are covered by `npm run test:licensed-models`.
