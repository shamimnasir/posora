# Ikan Goreng photogrammetry model

- Source: [Sketchfab — Ikan Goreng](https://sketchfab.com/3d-models/ikan-goreng-833b9c3ec4284047ac0b4b5cc35e9928)
- Creator: [wox080xow](https://sketchfab.com/wox080xow001)
- License: [Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/).
- Educational role: a generic whole fried-fish example for Food → বাংলার খাবার → মাছ ভাজা. The model is not identified as a Bangladeshi fish species or a Bangladesh-specific recipe.
- Web model: `ikan-goreng.glb`; simplified for mobile rendering and texture-compressed, quantized and Meshopt-compressed. Source identity and hashes are recorded in [asset-manifest.json](asset-manifest.json).
