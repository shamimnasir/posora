# Luna: asset preparation

Wait for the approved category brief. Produce the smallest useful asset set in the owned directory. Search source/license pages, verify the exact asset's CC0 or permissive commercial reuse license, and record source URL, author, license URL and text, attribution requirements, local filenames, SHA-256, units, orientation, bounding box, texture sizes, mesh names, animation clips, modifications and LOD variants in asset-manifest.json. Unknown license means unusable until verified. Do not invent assets or download URLs. Do not buy assets or upload private material.

Inspect a render of the asset: silhouette, proportions, texture seams, material response, detached anatomy and leaf alpha. Retain any required notices. Prefer GLB with PBR materials; glTF with external files remains acceptable if every dependency is recorded. Compression needs supported decoders and measured savings. Do not mark GLB conversion/compression as complete without running it. Keep authored subject assets distinct from decorative assets. The existing Anthurium is not a botanically accurate replacement for a mango tree.

If no suitable asset is available, report needs-assets with a precise modeling brief and candidate sources. Do not substitute a generic sphere and report success. No global loader edits in this task.
