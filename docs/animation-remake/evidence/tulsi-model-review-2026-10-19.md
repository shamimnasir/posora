# Tulsi candidate visual review — 2026-10-19

- Candidate: [Tulsi Tree on a cement tub by Prakash.Chatterjee](https://sketchfab.com/3d-models/tulsi-tree-on-a-cement-tub-29e20a3ac415461fa12930d04282163c)
- Listing license: CC BY 4.0; the listing says commercial use is allowed with creator attribution.
- Candidate downloaded as the Sketchfab 1K GLB, then optimized with glTF Transform 4.5.1 from 14.58 MB to 2.47 MB. The derived file is retained outside the site at `/tmp/tulsi_tree_candidate_rejected.glb`; the original download remains in the owner's Downloads folder.
- Technical desktop/mobile smoke tests passed, but the visual review failed. In both captures the dominant cement pot and sparse, thin plant silhouette make the selected object difficult to recognize as Tulsi. This is not an acceptable educational replacement, despite the compatible license and successful parsing.
- Decision: reject; do not publish or count as model coverage. Keep the existing figure until an accurate, clear candidate is found.
- Evidence: [desktop capture](evidence/licensed-models/desktop-life-tulsi-tree.png), [mobile capture](evidence/licensed-models/mobile-life-tulsi-tree.png).
