# Posora printable pilot

Use this protocol with 5 parent–child pairs before changing the pack content. Test one mission from Nature Guardian, Math Play, and Bangla Starter. Do not coach the child unless safety requires it.

## Session (30 minutes)

1. Give the child the mission opener and say: “তুমি কী করতে হবে বলবে?” Record the first action without explaining.
2. Let the child choose a difficulty and complete the warm-up.
3. Run one core worksheet and one movement/scavenger task.
4. Let the child use the cut-out/toolkit page and unlock the mission map.
5. Ask the child to explain one answer and complete the reflection.
6. Ask the parent to repeat the activity setup using only the parent card.

## Observe, do not lead

Record timestamps for: first understanding, first hesitation, first independent success, help request, completion, and voluntary return to an earlier task. Note every instruction the child asks to have reread.

## Pass criteria

- Child identifies the first action within 30 seconds.
- Child can choose a difficulty without adult interpretation.
- Child completes the core activity with no more than one clarification.
- Movement activity takes 5–10 minutes and uses ordinary household items.
- Parent can set up the activity in under 3 minutes.
- At least 4 of 5 children finish the mission map.
- At least 3 of 5 children choose to continue or repeat a task.
- No factual, safety or Bangla-wording error is observed.

## Interview questions

### Child

- কোন অংশটা সবচেয়ে মজার ছিল?
- কোথায় আটকে গিয়েছিলে?
- তুমি কি আবার খেলতে চাও? কেন?
- কোন শব্দ বা ছবিটা বুঝতে কষ্ট হয়েছে?

### Parent

- শুরু করতে কত সময় লেগেছে?
- কোন নির্দেশনা অস্পষ্ট ছিল?
- শিশুটি কী শিখেছে বলে আপনার মনে হয়েছে?
- এই প্যাকের জন্য টাকা দেওয়ার সবচেয়ে বড় কারণ কী হবে?
- কোন অংশ বাদ দিলে প্যাকটি দুর্বল হয়ে যাবে?

## Decision rules

- If two children miss the same instruction, rewrite it before adding content.
- If children finish early, add a harder choice challenge—not more explanation.
- If the movement task needs special materials, replace it with a household alternative.
- If a child enjoys a page but cannot explain the learning, simplify the task goal.
- If parents love the activity but cannot set it up, improve the parent card before redesigning the page.
